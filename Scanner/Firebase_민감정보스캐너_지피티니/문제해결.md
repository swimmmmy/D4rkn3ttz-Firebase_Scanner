# 문제 해결

## PowerShell 실행 정책

현재 창에서만 `Set-ExecutionPolicy -Scope Process Bypass`를 사용합니다. 영구 정책은 변경하지 않습니다.

## Defender 경고

`SHA256SUMS.txt`로 hash를 확인하고 사내 보안 절차에 따라 서명되지 않은 PyInstaller 파일을 검토합니다. 경고를 자동 우회하지 않습니다.

## 401 / 403

Scope가 맞는지 먼저 확인합니다. 401은 token 문제, 403은 Rules/App Check/IAM 거부일 수 있습니다. 다른 사용자의 credential을 시도하지 않습니다.

## 인증서 오류

시스템 시간과 조직 TLS 프록시의 신뢰 체인을 확인합니다. TLS 검증을 끄지 않습니다.

## Firestore path 미발견

정적 AST에서 복원 가능한 경로나 Scope의 `allowed_paths`를 추가합니다. collection/document 이름 brute force는 하지 않습니다.

## Emulator 미설치 / Java 없음

Java 21과 Node.js 20+를 준비한 뒤 `.\설치.ps1 -IncludeEmulator`로 고정된 Firebase CLI와 `@firebase/rules-unit-testing`을 설치하고 `test-rules`를 재실행합니다. 운영 Project ID 대신 demo project만 사용합니다.

## 포트 충돌

`app/tests/emulator/firebase.json`의 loopback port를 사용 가능한 값으로 변경합니다. 외부 interface에 bind하지 않습니다.

## 한글 경로

PowerShell 7 또는 `실행.ps1`/`실행.bat`을 사용합니다. 스크립트는 UTF-8을 활성화합니다.

## Checksum

```powershell
Get-FileHash .\FirebaseSecurityAuditor.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

불일치하면 파일을 실행하지 말고 다시 배포받습니다.
